# CampusFriend Mobile App

This directory contains a Flutter mobile app scaffold for CampusFriend.

## Getting started

1. Install Flutter: https://flutter.dev/docs/get-started/install
2. Open a terminal in the `Mobile` directory.
3. Run `flutter pub get`.
4. Run `flutter run` to launch the app on a connected device or emulator.

## Structure

- `lib/main.dart` — application entrypoint
- `lib/app.dart` — app and route configuration
- `lib/screens/` — login and home screens
- `lib/services/` — API and auth service integration

## Notes

This scaffold is built manually because Flutter CLI is not available in the current environment.
You can extend it with additional screens and backend features as needed.
